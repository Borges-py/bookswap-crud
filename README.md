# bookswap-crud
📚 BookSwap | Sistema de Troca de Livros
Este projeto é uma aplicação web simples que implementa as funcionalidades básicas de um CRUD (Create, Read, Update, Delete), permitindo que usuários gerenciem (cadastrem, visualizem, editem e excluam) livros disponíveis para troca.

Desenvolvido para consolidar conhecimentos em integração entre frontend e backend e manipulação de banco de dados em um contexto prático.

✨ Tecnologias Utilizadas
Backend: PHP (para a lógica de manipulação de dados e interação com o banco).

Frontend: HTML5 e CSS (para a estrutura e design básico).

Interatividade: JavaScript puro (para manipulações dinâmicas simples na interface).

Banco de Dados: MySQL

🚀 Funcionalidades Principais
Cadastro de Livro (Create): Inserir novos livros disponíveis no sistema.

Listagem de Livros (Read): Visualizar todos os livros cadastrados em uma tabela.

Edição de Livro (Update): Modificar as informações de um livro existente.

Exclusão de Livro (Delete): Remover um livro do sistema.
